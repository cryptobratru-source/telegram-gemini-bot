# Telegram Gemini Bot

Бот для Telegram, который использует Google Gemini API для участия в групповых чатах с бесконечной памятью.

## Установка и запуск (локально на ПК)

### 1. Установи Python
Скачай Python 3.10+ с https://www.python.org/downloads/ (если еще не установлен)

### 2. Установи библиотеки
Открой терминал в папке `telegram_gemini_bot` и выполни:
```bash
pip install -r requirements.txt
```

### 3. Запусти бота
```bash
python telegram_gemini_bot.py
```

Бот запустится и будет работать, пока терминал открыт.

### 4. Добавь бота в группу
1. Зайди в свою Telegram-группу
2. Нажми "Добавить участников"
3. Найди `@balamut_gemini_bot` и добавь

### 5. Как общаться с ботом
- **Упомяни бота**: `@balamut_gemini_bot привет!`
- **Ответь на сообщение бота**: Reply на его сообщение

Бот видит всю историю чата и помнит контекст.
